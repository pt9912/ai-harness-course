# Beobachtungs-Register

Je Beobachtung ein Verzeichnis `BEO-<KUERZEL>/<slug>/` mit `observation.md`
(Identität, unveränderlich), `state.md` (Stand) und `evidence/<vorgangs-id>.md`
(je Auftreten eine Datei).

**Der Zähler steht nirgends.** Er ist die Zahl der Evidence-Dateien.

Das `<KUERZEL>` wird aus der Modus-Deklaration in
[`harness/conventions.md`](../../../../harness/conventions.md) nachgeschlagen,
nicht formuliert.

Regeln: [Modul 6 §Das Beobachtungs-Register](../../../../../../kurs/de/02-planung/modul-06-roadmap.md#das-beobachtungs-register).

Diese Datei existiert ab Repo-Beginn — ein leeres Verzeichnis führt `git`
nicht, und ohne sie wäre *nichts beobachtet* nicht von *nie geführt* zu
unterscheiden.
